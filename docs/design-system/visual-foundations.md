# 视觉基础

## 颜色

浅色页面以 `#F4F0E6` 为基底，比参考古纸的中位色 `#DACFB3`
更白、更克制；深色页面使用 `#24231F` 灰黑纸张，不使用纯黑。正文分别使用
`#27241F` 与 `#E7E1D6`，印泥强调分别使用 `#B34A32` 与 `#CE6F54`。

全部组件色彩必须经 `--yoyi-color-*` 语义变量使用。`text-primary`、
`text-secondary`、`text-tertiary`
和印泥色在对应页面背景上满足普通正文对比要求；disabled 状态不承载必要信息。

## 排版

普通文字使用系统字体栈：Apple 系统字体、PingFang SC、Hiragino Sans GB、Microsoft
YaHei、system-ui、sans-serif。移动/桌面字号由 CSS
variable 在 896px 切换；正文保持 16px 与 1.75 行高。

底部导航的“首页、碑刻、书帖”使用用户提供图片裁切得到的三个透明 PNG 作为 CSS
mask，并随导航状态使用当前主题色，避免源图灰色像素在浅色或深色模式中显现；顶部“发现、时间轴”、动态标题、检索结果和用户内容均使用系统字体真实文本。

## 纸张纹理

四种纹理均使用 384×512 透明平铺 SVG：纵向纤维、低频色差和细颗粒分别由独立
`feTurbulence`
层生成。手机主界面使用 visible 版本，其他长期阅读面可使用 subtle 版本；透明度不高于 6.8%，不得叠加折痕、烧边或位图。

## Surface 与 Functional Glass

内容、Surface 与 Functional
Glass 严格分层。碑刻图片、拓片、专题正文和内容卡片继续使用不透明纸墨 Surface；Glass 只属于导航与经过单独授权的功能控件层。共享 token 提供 subtle、regular、prominent 三种语义，本期主导航只使用可读性优先的 regular。

支持背景模糊时，regular 使用主题适配的半透明纸色、20px
blur、轻量 saturation、边缘高光和阴影；不支持时回退到接近不透明的 elevated
Surface。降低透明度或提高对比偏好会直接使用不透明 Surface。页面和功能样式不得复制 Glass 的 rgba、blur 或 shadow 参数。

## 响应式

- 360/390px 竖屏：双列图片流、横向滚动标签、固定三项底栏；手机主预览画布最大宽度430px。物理手机横屏保持同一底部 Tab
  Bar，不升级为侧轨。
- 768px：平板全宽布局，继续采用触控向主导航（竖屏持久底栏 / 横屏持久浮动左栏），增加内容留白与卡片宽度。
- 896px：切换为桌面左侧主导航；首页与书帖用 `auto-fit`
  网格放大铺满剩余宽度；碑刻列表全宽放大。
- 1024/1440px：提高卡片最小宽度与碑刻行高；详情阅读宽度 760px；设置区可达 1200px。

交互原型与公共组件遵循同一套断点语义。组件目录中的手机画布演示仍可按需限制宽度，正式接入页面应按上述公共断点响应。
